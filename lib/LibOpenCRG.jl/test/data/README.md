# Test data

Copies of two small sample files from <https://github.com/asam-ev/OpenCRG>
(v2.0.1), so that this package's tests do not depend on files outside
`lib/LibOpenCRG.jl`:

- `handmade_curved_minimalist.crg`
- `handmade_curved_banked_sloped.crg`

The larger `belgian_block.crg` sample lives only in the repository-root
`test/data` and is not used by these tests.
